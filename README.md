# 👁️ Eye Patch Hero

Веб-додаток для тренування зору дітей, які носять occlusion patch (пов'язку для ока).

## 🎮 Особливості

- **3 міні-ігри** для тренування зору:
  - Catch the Dot - відстеження рухомих об'єктів
  - Focus Grid - знаходження відмінностей
  - Moving Contrast - тренування контрастної чутливості

- **Налаштування для батьків**:
  - Регулювання складності
  - Тривалість сесій (5, 10, 15 хв)
  - Увімкнення/вимкнення звуку
  - Вибір мови (UA/EN)

- **Система прогресу**:
  - Відстеження пройдених вправ
  - Історія сесій
  - Статистика успішності

## 🚀 Швидкий старт

```bash
# Встановити залежності
npm install

# Запустити dev сервер
npm run dev

# Збілдити для production
npm run build

# Запустити production сервер
npm start
```

Відкрийте [http://localhost:3000](http://localhost:3000) у браузері.

## 📦 Технології

- **Next.js 15** - React framework з App Router
- **TypeScript** - типізація коду
- **TailwindCSS** - стилізація
- **Framer Motion** - анімації
- **Zustand** - управління станом
